# MessengerApp - Android Мессенджер

Простое приложение мессенджера для Android, написанное на Kotlin с использованием Jetpack компонентов.

## Технологии

- **Язык**: Kotlin
- **UI**: ViewBinding, RecyclerView
- **База данных**: Room Database
- **Асинхронность**: Kotlin Coroutines, Flow
- **Архитектура**: MVVM (Model-View-ViewModel)

## Структура проекта

```
app/src/main/java/com/example/messenger/
├── MainActivity.kt          # Главная активность
├── model/
│   └── Message.kt           # Модель сообщения
├── database/
│   ├── AppDatabase.kt       # Конфигурация Room базы данных
│   └── MessageDao.kt        # DAO для работы с сообщениями
└── ui/
    └── MessageAdapter.kt    # Адаптер для RecyclerView
```

## Функционал MVP

- ✅ Отправка сообщений
- ✅ Отображение списка сообщений
- ✅ Локальное хранение в Room базе данных
- ✅ Автоматическая прокрутка к новому сообщению
- ✅ Разделение стилей для отправленных и полученных сообщений

## Как запустить

1. Откройте проект в **Android Studio**
2. Дождитесь синхронизации Gradle
3. Запустите на эмуляторе или реальном устройстве

## Требования

- Android SDK 24+
- Android Studio Arctic Fox или новее
- Kotlin 1.9.0+
